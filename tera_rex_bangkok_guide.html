這是出發前自由活動攻略，不是已訂行程。商場店家、樓層、按摩價格與現場營業情況可能變動。Tera／Rex 先去 EMSPHERE；豪億與朋友抵達 Asok 後可選 Terminal 21。請以司機與群組通知為準，18:00 集合出發。

✈️ BKK 機場｜出關、換匯、集合

全團約定集合：航廈 2F 入境大廳，3 號出口（Gate / Door 3）附近。這是團隊約定的見面位置，不代表司機一定能停在門口。出關後先在 LINE 報平安；司機到達、實際上車位置以司機通知為準。不要自行走到 1F 計程車排隊區。
出關後第一步
2F Arrival Hall → Gate 3

依序通過移民官查驗、領取行李、海關，進入 2F 公共入境大廳；跟著數字 3 找到 3 號門附近的會面點。抵達後先傳訊息給團主／司機，確認目前等待時間。

📍 3 號門地圖機場樓層與接機說明
司機還沒到？可以先換錢
B 樓｜SuperRich Orange（橘色）

從 2F 搭電梯或手扶梯到 B 樓（Airport Rail Link 機場快線樓層），找 Zone C、靠近機場快線售票櫃檯的橘色 SuperRich。官方 2026/11/3 新開分店公告：每日 05:00–00:00。也可在附近比較其他合法換匯櫃檯當日牌價。請帶護照正本與現金，注意鈔票狀況。

📍 B 樓換匯導航官方分店公告
等車時簡單逛
機場內的休息與補給

2F 入境大廳先找洗手間、便利商店、飲料與電信櫃檯；想吃東西可到 3F 公共餐飲區，或依機場指標找其他開放的餐飲設施。店家與營業狀況以當日為準，這裡不預設特定品牌一定有營業。

重要：先確認司機還有多久才到。若只剩 10–15 分鐘，建議直接在 2F Gate 3 附近等待；若要下 B 樓換匯，預留返回 2F 的時間，並隨時看 LINE。行李不要無人看管。

等待情境快速判斷

🟢 司機還要 30 分鐘以上：可去 B 樓換匯，回 2F Gate 3 等。

🟡 還要 15–30 分鐘：附近買飲料、上洗手間，不要走遠。

🔴 司機快到了：留在 2F Gate 3，手機保持可聯絡。

以上為建議緩衝，不是保證行走時間；人潮與排隊會影響返回速度。

✈️ Terminal 21 Asok｜民宿旁的備用行程

這裡是 Asok 的 Terminal 21，不是 Pattaya 的 Terminal 21！適合豪億與朋友抵達民宿後直接逛，也適合 Tera、Rex 提早逛完 EMSPHERE 後順路去。商場一般營業 10:00–22:00，當日仍以現場公告為準。 換匯可直接看下方「💱 換匯與現金」的 Terminal 21 G 樓資訊。
第一站：不用想太多
5F｜Pier 21 平價美食街

泰式炒河粉、打拋飯、海南雞飯、船麵、甜品等攤位集中。先在櫃檯購買儲值卡，再到攤位點餐；用完把卡拿回櫃檯退還餘額。價格比周邊百貨餐廳親民，實際價格看現場菜單。
